# Bitácora de Obra
## Presentación breve para usuarios ALFA / BETA

Bitácora de Obra es una mini aplicación pensada para organizar información de obra de forma simple, directa y fácil de consultar.

Bitácora se organiza en cinco **Secciones**:

- **Notas**
- **Documentos**
- **Materiales**
- **Catálogos**
- **Planos**

## ¿Cuál es la sección principal?

La sección principal es **Notas**.

Ahí se registran actividades, avances, ideas, observaciones y referencias del trabajo cotidiano.  
Con el tiempo, esa sucesión de notas forma la verdadera bitácora de la obra.

## ¿Para qué sirven las demás secciones?

Las demás secciones funcionan como apoyo y consulta:

- **Documentos**: instructivos, informes, memorias y otros archivos de referencia
- **Materiales**: recursos, muestras, fotos, videos y elementos vinculados a la obra
- **Catálogos**: catálogos de productos o materiales para consulta
- **Planos**: planos y archivos gráficos relacionados con la obra

## Idea general de uso

La lógica más simple de trabajo es esta:

1. registrar lo importante en **Notas**
2. usar las demás secciones como material de apoyo
3. consultar, relacionar y volver sobre la información cuando sea necesario

## En esta etapa BETA

Durante esta etapa el sistema ya se puede usar con normalidad, pero todavía está en observación y ajuste.

Eso significa que:

- algunas opciones podrán simplificarse todavía más
- algunos nombres o clasificaciones podrán ajustarse
- se seguirán mejorando pequeños detalles de uso

## Objetivo de esta etapa

El objetivo no es que todo esté perfecto, sino comprobar que Bitácora resulte:

- clara
- cómoda
- útil
- fácil de aprender
- fácil de usar en el día a día

## Idea final

Bitácora no busca ser complicada ni técnica.  
Busca ayudarte a registrar, consultar y ordenar información de obra de una manera simple.
